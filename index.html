PROGRAMS

Three development threads, one system-level engineering approach.

Peregrine is converging mission software, airborne communications and sensing, and a future purpose-built aircraft into a common architecture. Public descriptions are intentionally limited to non-sensitive development information.

FOVEA ENGINESOFTWARE // ENGINEERING MVP

Mission, tracking, cooperative fusion, radar-control, simulation, and operator software.

FOVEA is the mission software stack supporting PACN-01 development. The Peregrine Mission Console provides the operator-facing environment for scenario construction, geographic operations, track inspection, replay, network topology, cooperative-source visualization, and decision provenance.

  • Native simulation and mission-state runtime
  • Tracking and cooperative multi-source fusion
  • Radar tasking / control adapter architecture
  • Offline-capable mission console and replay workflow

PACN-01SYSTEM // ACTIVE DEVELOPMENT

A modular airborne edge node for communications, sensing, and distributed mission operations.

PACN-01 has evolved beyond the original airborne relay concept. The current development architecture combines configurable RF interfaces, sensor/radar integration points, edge mission compute, cooperative track exchange, and FOVEA mission services.

Hardware and airframe integration remain development activities; public specifications are design objectives until verified in prototype and flight test.

EXPLORE PACN-01 →
P-360 STOOPAIRCRAFT // DESIGN-STAGE

A Group 3 VTOL aircraft concept intended to carry persistent sensing and communications payloads.

P-360 is Peregrine's purpose-built airframe development path for later phases of the architecture. Current work is design and analysis, with radar-node and extended-mission variants under study.

Published P-360 performance values are engineering targets, not flight-verified performance.
